# Product: Opções

Plataforma para monitoramento e gestão de opções (CALLs/PUTs) da B3.

## Core Value Proposition
Fornecer ferramentas para coleta de dados, ranqueamento de oportunidades, gestão de portfólio e conformidade fiscal (DARF) para investidores de opções no mercado brasileiro, com foco em estratégias de Cash-Covered Put e Covered Call.

## Key Features
- **Scraper Automático:** Coleta diária de dados do opcoes.net.br via Playwright.
- **Ranking de Oportunidades:** Algoritmo de score baseado em moneyness, liquidez, IV e risco.
- **Gestão de Estratégias:** Apoio para estratégias de lançamento coberto e venda de put.
- **Gestão de Posições:** Acompanhamento de P/L e histórico de operações.
- **Módulo Fundamentalista:** Integração com dados do Fundamentus e Status Invest.
- **Módulo Fiscal:** Cálculo de DARF para operações com opções.
- **Interface Web:** Dashboard para visualização de rankings, posições e configurações.
